# Part8 Block3 — denied-action lifecycle evidence simulation

`summarizeDeniedActionLifecycle` receives only caller-supplied denied dispatch previews, revalidates each against the preflight using the canonical pure preview contract and rejects mismatched/forged status, effects, authority, tenancy, mode or lineage. Identical preview IDs are deduplicated deterministically within one bounded 1–10 input array; a conflicting duplicate fails closed. The output retains proposal/plan/review/intent source references and explicit uncertainty, and asserts actualHumanApproval / actualBusinessOsDispatch / actualProviderEffect = false. `SIMULATED_DENIAL_ONLY`, `NOT_DURABLE` and `INPUT_PREVIEWS_NOT_AUDIT_EVENTS` prohibit interpreting this as an audited real event or transactional durable idempotency. Demo, Sandbox and Production share identical safeguards; no provider, Business OS domain service or operational database is invoked. Real server identity, authorization/revocation, independently authenticated evidence, human attestation, durable audit, idempotency, replaceable provider adapters, staged runtime validation and monitoring remain deferred. All scheduled CIGO automations disabled.
