# Part7 Block3 — review request and read-only conversation context

`prepareCopilotReviewHandoff` builds an inert, workspace-scoped human-review REQUEST from an unverified read-only response. It does not attest reviewer identity, record a decision, grant approval or execute tools. `summarizeCopilotConversation` projects at most ten supplied responses for one workspace and one proposal/plan lineage, with unique question IDs and unverified citations. Caller-provided turns are not authenticated history or persisted memory. Neither function interprets prompt text, calls an LLM, contacts a provider, schedules work or promotes draft content to FACT. Independent human attestation, authenticated sessions, durable audit/replay and production Business OS integration remain deferred. Demo/Sandbox-compatible pure contracts only; scheduled CIGO automations disabled.
