# Part4 Block2 — Bounded deterministic business metrics

`analyzeBusinessMetrics` consumes only explicitly supplied approved-source-shaped projections through a trusted workspace context. The caller of this pure domain function is responsible for obtaining authorized read-only projections and authenticating the workspace; production integration is not implemented. It does not infer data from memory prose, query providers, write operational records, or claim source authenticity. Supported domain tags are leads, conversion, appointments, missed enquiries, revenue/cost, marketing, retention and capacity. Each metric is a declared source numerator with optional denominator, period, observation time, integer count or minor-currency unit, fingerprint references and completeness.

A metric is AVAILABLE only when its projection is complete, temporally current and has a valid nonzero denominator when applicable. Partial/stale/future/zero-denominator inputs return null with explicit limitations. Duplicate domain/key/period/unit projections are rejected rather than reconciled speculatively. Values are unrounded deterministic ratios or source-unit integer totals, never fabricated percentages or currency conversions. Output is always ANALYSIS, SOURCE_UNVERIFIED, non-actionable, defensively cloned. A fingerprint is a reference, not verification. Maximum 100 projections per call; no silent truncation. The source contract intentionally does not assert that any particular metric is available for any workspace.

Production gates remain: authenticated projection source and revocation, independently verified provenance and completeness, durable storage, live Business OS read-model adapter, domain-specific numerator/denominator semantic validation and currency identity, financial reconciliation, concurrency, security and deployment. This reference block does not establish these gates.
