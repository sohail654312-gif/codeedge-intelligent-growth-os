# M-02 — Business metric semantic identity (scoped reference correction)

The previous generic `domain + metricKey + COUNT/MINOR_CURRENCY_UNITS` projection could label incompatible quantities as comparable. `src/analysis/business-metrics.ts` now provides a **closed v1 catalog** with domain, metric key, numerator and denominator meaning, unit, aggregation (`SUM` or `RATIO`) and definition version. Unknown measures, mismatched domain/unit/version and semantically inappropriate denominator are rejected. Ratios require numerator and denominator to describe the named cohort and numerator cannot exceed denominator. Zero denominators produce `UNAVAILABLE` rather than false numeric conclusions.

Every input declares `sourceContractVersion: "business-os-read-model:v1"`, `metricDefinitionVersion: "v1"`, and `windowTimezone: "UTC"`; reporting periods are canonical UTC midnight inclusive start and exclusive end. Inputs using local timezone/DST or unknown source versions fail closed; aggregation of separate windows, source revisions or unlike definitions is not implemented. The source projection is still UNVERIFIED and non-actionable, not an independently attested FACT.

Currency metrics are integer **minor units** and require an explicitly recognized ISO 4217 currency identity (currently GBP, USD, EUR, PKR, AED, CAD, AUD, INR, SGD, NZD). No conversion, FX inference, currency arithmetic or silently merged cross-currency duplicate window is performed. A currency mismatch cannot distinguish two conflicting copies of the same key/window. Source adapters must provide valid minor-unit precision and independently reconcile totals to Business OS operational records before real finance reporting; this implementation is not an accounting integration.

The closed catalog currently contains: LEADS/leads-created and lead-qualification-rate, CONVERSION/lead-conversion, APPOINTMENTS/appointments-booked and appointment-attendance-rate, MISSED_ENQUIRIES/missed-enquiries, REVENUE_COST/revenue-gross and cost-total, MARKETING/marketing-spend, RETENTION/customer-retention, CAPACITY/available-slots. An addition or semantic revision must be reviewed and versioned; the analysis function never fabricates metric meaning from arbitrary labels. Old generic test fixture keys were deliberately replaced by catalog-conforming examples.

Tests in `test/business-metrics.test.mjs` cover domain mismatch, source/version mismatch, UTC window rules, arithmetic/cohort constraints, missing/unsupported currency, conflict across currency labels, provenance/partial/stale uncertainty and non-effect semantics. This is M-02 `IMPLEMENTED_PENDING_INDEPENDENT_REVIEW` and does not satisfy deployed production auth, source-semantic reconciliation, real FX/data-integrity or any G1–G8 gate. All gates remain OPEN.
